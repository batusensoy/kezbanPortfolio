# Architectural Decision Records (ADRs)

## ADR-001: Workspace Skills Architecture
- **Date**: 2026-11-09
- **Status**: Accepted
- **Context**: The portfolio requires high-craft design engineering, rigorous security, resilient testing, and zero-defect development workflows.
- **Decision**: Adopt a modular 18-skill suite stored in `.agents/skills/` adhering to the Antigravity progressive disclosure standard.
- **Consequences**: Standardized instructions, reusable interactive code examples, and reproducible quality gates across all development tasks.
