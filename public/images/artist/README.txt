# Artist Portraits & Studio Images Directory

Place photographs of the artist and studio atmosphere here:
`public/images/artist/`

### Recommended Image Specs:
- **Portrait**: `portrait.jpg` (Vertical portrait 3:4 aspect ratio, min 1200x1600px)
- **Studio Atmosphere**: `studio-1.jpg`, `studio-2.jpg` (Editorial studio shots)

Reference in `src/data/artist.ts` or page components as:
`image: '/images/artist/portrait.jpg'`
